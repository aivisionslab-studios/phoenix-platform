# onnxruntime: CPU por padrão. GPU (Windows + qualquer placa DX12, inclusive

# verdade nesta auditoria numa RX 580 real e FALHOU em todos os blocos
# (onnxruntime-directml não executa o nó ConvTranspose do vocoder do Kokoro
# nessa GPU/driver, erro nativo do Windows 80070057 "Parâmetro incorreto")
# - fique em CPU até esse gap de suporte a operadores ser resolvido em
# uma versão futura (driver AMD mais novo ou release futuro do onnxruntime-directml).
# Os dois pacotes são
# MUTUAMENTE EXCLUSIVOS (mesmo módulo Python), então só um dos dois deve

# variável de ambiente PHOENIX_TTS_DEVICE (ver install_phoenix.ps1) - troque
# "CPU" por "GPU" lá pra ativar. Instalação manual equivalente:
#   pip install onnxruntime>=1.25.0          # CPU (padrão)
