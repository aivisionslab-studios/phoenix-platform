# Phoenix Engine — Regras de Desenvolvimento

1. **Testes Unitários Obrigatórios:** Toda alteração no domínio deve incluir testes.
2. **Evolução por Composição:** Novos componentes devem ser integrados sem sobrescrever arquivos inteiros.
3. **Domínio Isolado:** O domínio não deve conhecer detalhes de infraestrutura.
